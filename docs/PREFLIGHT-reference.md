# PREFLIGHT — Sourcing Session Checklist

Read this before every sourcing session. Read it again if you catch yourself drifting.

## NEVER DO THESE THINGS
1. **Never click "Similar Profiles"** — navigates away from search to a SEPARATE landing page. Forbidden. This includes: do NOT click any link in the "Similar Profiles" section at the bottom of profile pages. When returning from a profile to search results, navigate directly to the saved search URL.
2. **Never click "Clear All" / "Clear Search"** — wipes Location and all permanent filters. Each filter has its own clear button. Use those only.
3. **Never use the top navigation search bar** — that's global search, not project search.
4. **Never click Skills filters, job title links, or any link that leaves search results.**
5. **Never chain more than one navigation action without yielding.** Every click that changes page state (opening a profile, clicking Save, paginating) = end of turn.

## ALLOWED CLICKS
- Keywords field (sidebar) ✅
- Individual filter clear buttons ✅
- Pagination (next page) ✅
- Profile cards (to open full profile) ✅
- "Save to pipeline" button ✅
- Back button (to return to results) ✅

## TURN CADENCE
- **Scan turn:** ~10 previews → send quick scan report → yield
- **Eval turn:** Open 1 profile → read → save/skip decision → send detailed eval via WhatsApp → yield
- **Page summary turn:** Running totals, moving to next page → yield
- **Rule:** Every navigation action that could break state must be followed by a yield before the next navigation action.

## BEFORE STARTING
- [ ] Confirm brief, kit, project, resume point with Sam
- [ ] Verify Location filter is set
- [ ] Verify Keywords field is clear
- [ ] Read mistakes.md
- [ ] Wait for Sam's explicit go-ahead

## DURING SESSION
- Never go silent for more than one scan batch
- If stuck for >15 seconds, screenshot and report immediately
- If Sam sends a message, acknowledge and act on it in the next turn
- Log every opened-and-evaluated candidate in the progress file decisions array

## AT /stop
- Halt immediately — do not finish current action
- Save progress file with exact state
- Write memory/YYYY-MM-DD.md with: what happened, what went wrong, where to resume
- Send stop confirmation with string/page/save counts
