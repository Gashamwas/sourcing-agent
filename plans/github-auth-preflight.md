# GitHub Auth Preflight

## Problem

The Colombia GitHub run started with an invalid `GITHUB_TOKEN`. Every GitHub API request returned `401 Bad credentials`, but the runner treated each failure as a per-query error and continued adapting the search plan. This wasted runtime and model calls.

## Scope

- Add a GitHub client auth preflight that runs before strategy formation.
- Raise a typed fatal auth error for GitHub 401 responses.
- Let the GitHub orchestrator stop the run immediately on auth failure.
- Return a nonzero process exit on fatal auth failure.
- Add focused tests for the preflight and query-loop behavior.

## Files

- `github/client.py`
- `github/orchestrator.py`
- `github/session_orchestrator.py`
- `tests/test_github_pipeline.py`

## Out of Scope

- Replacing or rotating the user's GitHub token.
- Changing the GitHub CLI auth flow.
- Editing output artifacts generated by the failed run.
